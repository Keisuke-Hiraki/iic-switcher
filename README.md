# IIC Switcher

複数の IAM Identity Center のアクセスポータルを 1 つの画面から開くための Chrome 拡張機能です。
ポータル URL を登録しておくと、ポップアップから個別ログインや一括オープンができます。

## 主な機能

- ポータルの追加・削除
- 登録済みポータルの一覧表示
- 個別ログイン（新しいタブで開く）
- 全て開く（登録済みポータルをまとめて開く）

## 使い方

1. Chrome の拡張機能ページ（`chrome://extensions/`）を開きます。
2. 右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本リポジトリのフォルダを選択します。
4. 拡張機能のアイコンをクリックしてポップアップを開きます。
5. 「表示名」と「アクセスポータル URL」を入力して追加します。

## URL の例

```
https://d-xxxxx.awsapps.com/start
```

## メモ

- 登録データは Chrome の同期ストレージ（`chrome.storage.sync`）に保存されます。
- 誤った URL を入力するとエラーメッセージが表示されます。

## 開発

この拡張機能は Manifest V3 に対応しています。必要に応じて `popup.html` / `popup.js` / `popup.css` を編集してください。
