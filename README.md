# IIC Switcher

複数の IAM Identity Center アクセスポータルを 1 つの画面で管理し、素早くアクセスできる Chrome 拡張機能です。
ポータル URL や許可セットを登録しておくと、ポップアップからログインやコンソール起動ができます。

## 主な機能

- ポータルの追加・編集・削除
- 登録済みポータルの一覧表示（ポップアップと設定画面）
- ポータルの並び替え（ドラッグ & ドロップ）
- ポータル単位のログイン（新しいタブで開く）
- 許可セットの追加・編集・削除と一覧表示
- 許可セットごとの AWS コンソール起動
- JSON でのインポート/エクスポート

## 使い方

1. Chrome の拡張機能ページ（`chrome://extensions/`）を開きます。
2. 右上の「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本リポジトリのフォルダを選択します。
4. 拡張機能のアイコンをクリックしてポップアップを開きます。
5. 「設定を開く」ボタンから設定画面に移動します。
6. 「追加・編集」タブで「表示名」と「アクセスポータル URL」を入力して追加します。
7. 必要に応じて「許可セット」タブでアカウント ID・アカウント名・許可セット名を登録します。
8. 「インポート/エクスポート」タブで JSON をまとめて追加できます。

## URL の例

```
https://d-xxxxx.awsapps.com/start
```

## インポート/エクスポート形式

```json
{
  "portals": [
    {
      "name": "本番",
      "url": "https://d-xxxxx.awsapps.com/start"
    }
  ],
  "permissionSets": [
    {
      "portalUrl": "https://d-xxxxx.awsapps.com/start",
      "accountId": "123456789012",
      "accountName": "production",
      "roleName": "AdministratorAccess",
      "note": "会計チームのみ利用"
    }
  ]
}
```

旧形式として、ポータル配列のみを JSON で渡すこともできます（permissionSets は空で扱われます）。

## メモ

- 登録データは Chrome の同期ストレージ（`chrome.storage.sync`）に保存されますが、許可セットが上限を超えた場合は許可セットのみローカルストレージ（`chrome.storage.local`）に保存されます。
- URL は `https://*.awsapps.com/start` の形式のみ登録できます。
- 誤った URL を入力するとエラーメッセージが表示されます。
- 許可セットの登録には 12 桁のアカウント ID が必要です。
- 許可セットを登録するとポップアップから直接コンソールを開けます。

## 開発

この拡張機能は Manifest V3 に対応しています。必要に応じて `popup.html` / `popup.js` / `popup.css` を編集してください。
